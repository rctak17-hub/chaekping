모임에 보일 내 이름을 등록해 주세요.
아직 서버에 연결하지 않았어요.

Google Apps Script 웹 앱 주소 또는 Firebase 실시간 DB 주소를 넣으면 자동으로 인식해요. 링크에 ?api=…&room=…이 붙어 있으면 자동 연결됩니다.

링크를 받은 모임원은 이름만 입력하면 바로 참여해요.

모임에 표시될 내 이름성탁
서버 연결 방법 (3분)
  1. Google 계정으로 script.google.com에 접속해 새 프로젝트를 만들어요.
  2. 함께 만든 독서모임-AppsScript.gs 내용을 통째로 붙여넣고 저장해요.
  3. 배포 → 새 배포 → 유형 웹 앱, 실행 나, 액세스 모든 사용자로 배포해요.
  4. 나온 웹 앱 URL을 위의 공유 서버 URL에 붙여넣고 [연결하고 동기화]를 눌러요.
  5. 초대 링크를 단톡방에 올리면 모임원은 이름만 넣고 참여해요.

Google Sheets가 무료 DB로 쓰이고, 모임방(책핑)별로 따로 저장돼요. Firebase를 쓴다면 실시간 DB 주소를 넣고 rooms 아래 읽기/쓰기를 허용하면 됩니다.

파일을 단톡방으로 나눠 줄 때는 모임원이 각자 독서장을 열어 모임 연결 설정에 같은 서버 URL과 모임 이름(책핑)을 넣어도 바로 참여돼요.

초대 링크를 아는 사람은 누구나 모임에 들어와 이름을 올릴 수 있으니, 단톡방 밖으로는 공유하지 마세요.
